# Java SOAP & JPA - Módulo 65

Proyecto Backend Java que integra servicios SOAP y persistencia mediante Spring Data JPA.

## Componentes

### Servicio SOAP

- Endpoint de servicio.
- Configuración de Web Services.
- Definición XSD.
- Aplicación Spring Boot.

### Spring Data JPA

- Controllers.
- DTOs.
- Repositories.
- Services.
- Configuración de persistencia.
- Pruebas automatizadas.

## Tecnologías

- Java
- Spring Boot
- SOAP
- Spring Data JPA
- Maven
- MySQL
- H2

## Ejecución

El proyecto utiliza Java 17 y Maven.

Para ejecutar las pruebas:

    mvn clean test

El entorno de desarrollo puede utilizar H2. La configuración de producción permite proporcionar las credenciales de base de datos mediante variables de entorno.
